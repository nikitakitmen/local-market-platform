# Паспорт оформления (определён по OOXML трёх эталонных ВКР)

Эталоны:
- **Э1**: Олейников Д. А., 107 с.
- **Э2**: Лянник Н. А., 81 с.
- **Э3**: Кашанский Н. И., 113 с.

**Основной эталон — Э3.** Это самый систематичный документ:
- отдельная секция титульного листа и нумерация с 2;
- единые абзацные отступы 709;
- подписи рисунков с интервалом 1,5;
- нет посторонних артефактов.

Э1 почти полностью совпадает с Э3, но в нём нет колонтитула с номерами страниц. У Э2 есть отклонения:
- текст «Оглавление» внутри поля TOC;
- жирные строки 1-го уровня в содержании;
- отступ 851 вместо 709;
- подписи рисунков с одинарным интервалом.

## Ошибки эталонов, которые не переносятся

- **Э1:** нет колонтитула, поэтому номера страниц не печатаются.
- **Э2:**
  - отступ 851;
  - лишний текст «Оглавление» в TOC;
  - жирный 1-й уровень содержания;
  - подпись рисунка отделена от рисунка;
  - ссылки с `utm_source=chatgpt.com`.
- **Э3:**
  - номер страницы синего цвета;
  - дублированный номер «Рисунок 1.4»;
  - тире «—» в подписях 2.1–2.7;
  - нумерация «A.1» латинской A;
  - номер «Листинг Б1» без точки.

## Решения, принятые при сборке итогового документа

- **Основа.** За основу взят пакет Э3. Из него сохранены:
  - `styles.xml`, `settings.xml`, тема и таблица шрифтов;
  - параметры секций;
  - титульный лист: абзацы 0–30 с их `pPr`, табуляциями и отступами; заменены только тема, ФИО и руководитель.
- **Содержимое.** Всё содержимое сформировано заново. Старые тексты, рисунки, ФИО и `customXml` удалены, пакет проверен поиском.
- **Колонтитул.** Номер страницы стоит в простом абзаце справа (TNR 12, чёрный) вместо таблицы с синим текстом из Э3.
- **Абзац с рисунком** имеет одинарный интервал, чтобы Word не добавлял полуторный интервал к высоте изображения. Подпись центрируется без отступа первой строки: в Э3 он смещал подпись вправо.
- **Таблицы** оформлены по ГОСТ 7.32 (в эталонах их нет):
  - подпись над таблицей слева, 12 пт;
  - шапка повторяется на каждой странице;
  - строки не разрываются.
- **Оглавление** — поле TOC. Номера страниц вычислены по сверстанному документу, все 36 строк сверены с PDF.
  - Стили «toc 1–3» доведены до вида эталонного содержания: 1,5, по ширине, TNR, 3-й уровень курсивом. Поэтому после обновления поля в Word вид содержания не меняется.
  - В `settings.xml` включено обновление полей при открытии: Word спросит «Обновить поля?», нужно ответить «Да».
- **Список источников** пронумерован в порядке первого упоминания в тексте.
- **Данные титульного листа взяты из Э2** (студент Лянник Н. А., руководитель ст. преп. Котова О. В.), вид работы — «Выпускная квалификационная работа». Если данные другие, их нужно поправить.
